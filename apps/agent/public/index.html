Letterlock memory agent

An ERC-8004 agent that seals notes to a person's Letterlock address: it reads their passkey-derived key from the Letterlock directory on Monad and encrypts to it with HPKE, so only their passkey can open the note.

Not live yet Its endpoint, POST /remember, goes live in the next build phase. Today it does not answer.
